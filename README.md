# 🧮 Calculator CLI

A simple command-line calculator built with pure Python — no external libraries, just clean logic.

بسيطة، سريعة، وبتغطي كل الـ operators الأساسية اللي محتاجها أي calculator.

---

## ✨ Features

- Supports `+`, `-`, `*`, `/`, `%`, and `**` (power)
- Handles division by zero safely
- Input validation (catches invalid numbers with `try/except`)
- Keeps running in a loop until the user chooses to quit
- Clean, beginner-friendly Python — no libraries needed

## 🚀 How to Run

```bash
git clone https://github.com/Mohamed14209/calculator-cli.git
cd calculator-cli
python "Calculator .py"
```

## 🎮 Example

```
Enter the first number: 10
Enter the operator (+, -, *, /, %, **): *
Enter the second number: 5
The result is: 50
Do you want to perform another calculation? (y/n): n
Goodbye!
```
